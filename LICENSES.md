## License Compliance Notes

### For KRVPN Distributors:

1. **MPL-2.0 (Xray-core)**: Source code modifications must be made available. If you modify Xray-core, provide source under MPL-2.0.

2. **LGPL-3.0 (HEV SOCKS5 Tunnel)**: 
   - Must allow users to replace the library
   - Provide build scripts (`build_native.sh`)
   - Do not statically link without providing object files

3. **Apache 2.0 libraries**: Include license notices in your app (About → Open Source Licenses screen)

4. **BSD licenses**: Retain copyright notices in documentation

### Recommended App Implementation:

Add an "Open Source Licenses" screen in Settings/About that displays this document.
